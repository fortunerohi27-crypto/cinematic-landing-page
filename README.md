# Nex Studio — Cinematic Landing Page

A stunning full-stack cinematic marketing website for a creative studio. Built with **Next.js 14**, **TypeScript**, **Prisma**, and modern animations.

Live Demo: [Your Deployment URL]

## ✨ Features

- **Cinematic Scroll Experience** with smooth animations powered by GSAP, Lenis, and Framer Motion
- **3D Elements** using React Three Fiber and Three.js
- **Full Authentication** with secure password hashing (@node-rs/argon2)
- **Role-based Admin Dashboard** for content management
- **CMS Functionality**: Manage gallery, testimonials, contact submissions, and newsletter subscribers
- **Database**: Prisma ORM with SQLite (local) / PostgreSQL (production)
- **Modern UI**: Tailwind CSS with premium dark theme and glassmorphism effects
- **Protected Routes**: Middleware for admin and dashboard sections

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Framer Motion, Lenis
- **3D**: @react-three/fiber + @react-three/drei + Three.js
- **Database**: Prisma + SQLite/PostgreSQL
- **Auth**: Custom session-based with Argon2 hashing
- **Icons**: Lucide React
